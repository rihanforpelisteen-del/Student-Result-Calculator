# Student Result Calculator

A simple web application to calculate
student marks, percentage, grade and result.

## Features
- Enter student name
- Enter 5 subject marks
- Calculate total marks
- Calculate percentage
- Display grade
- Show Pass or Fail status

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the website.
2. Enter student name.
3. Enter marks in all 5 subjects.
4. Click Calculate Result.
5. View your result.
